# 海斗助手（海克斯大乱斗 实时出装 / 增幅 / 战术推荐）

**下载最新版：** [haidou-helper-main.zip](https://github.com/mingxintan-coder/haidou-helper/archive/refs/heads/main.zip)（解压后第一次双击 `start.bat`；之后用桌面上自动建好的「海斗助手」图标打开）

> **English:** Mayhem Helper — a live build/augment advisor overlay for League of Legends ARAM: Mayhem.
> Download the zip above, unzip, double-click `start.bat`. Switch the interface to English in the ⋯ menu →
> 「语言 / Language」→ English (or run with `--ui-lang en`), then restart. English mode also uses English item/champion/augment
> names (`en_US`) so augment-screen detection matches an English game client; use `--lang` to pick another client language.

## 使用
1. 安装 Python 3.8+（python.org，安装时勾选 “Add python to PATH”）。
2. 双击 `demo.bat` 先看效果（不用开游戏，会模拟一局装备变化、阵亡和一次三选一）。
3. 实战：游戏设置 → 视频 → 窗口模式改为「无边框」，进入对局后双击 `start.bat`，挂件会自动连接。
   第一次运行会自动安装屏幕识别组件（约 60MB，只需一次）。

首次运行会下载装备/英雄/增幅数据，之后缓存在 `%USERPROFILE%\.lol_haidou_helper\`。

## 数据自动更新（跟着海斗版本走）
- 每次启动、每局结束后、以及不在对局时每 30 分钟，自动检查：
  - 游戏版本（装备、英雄、技能、增幅）；
  - ARAMKit 海斗数据（胜率每天更新；海斗商店装备、增幅池、英雄平衡调整随海斗版本更新）；
  - 同一版本内的热修（增幅资料每天重新读一次）。
- 有新版本就在背景下载，**不会打断正在打的一局**：等这局结束或下一局开始前才换上，标题栏会显示「数据已更新 ✓」。
- 换上新数据后自动删除旧版本的缓存，不会越积越多。
- 版本新出的英雄：连招和定位（治疗、控制、开团、消耗、辅助）会按技能描述自动推导。
- 想马上检查或更新：⋯ →「更新」（有新版就直接下载更新，没有就检查一次）。鼠标移到底部「游戏 … · ARAMKit …」上可以看到当前数据版本和上次检查结果。

## 界面
- **三个分页**：出装（战术要点＋鞋子＋装备）｜增幅（三选一评分 / 当前局势推荐）｜玩法（海斗平衡、加点、召唤师技能、连招）。
  出现三选一会自动切到「增幅」，选完回到原来那页；开局自动显示「玩法」。
- 每项一行：左边分数（绿≥80、黄≥65），右上是网上胜率和购买提示，下面一行是原因；**鼠标移上去看完整理由**。
- 平时收成一行（下一件装备＋鞋子，或紧急战术／三选一推荐）。只有**你的推荐变了**或出现三选一才自动展开，5 秒后自动收起；
  别人买装备、升级不会弹开。鼠标在窗口上停 0.6 秒才展开（打团时划过去不会误弹），移开 1 秒收起；📌 固定展开（只在本次有效）。
- 标题栏：连线状态灯｜「识别 F8」识别三选一｜— 最小化｜📌｜⋯ 设置（字号、胜率分段、自建数据库、更新、关闭）。
  点底部「ARAMKit … ⇄」也能直接切换全部分段 / 高分段。标题栏可拖动，位置和设置都会记住。
- **语言 / Language**：⋯ →「语言 / Language」选中文或 English，重新打开后生效。英文界面会同时使用英文的装备/英雄/增幅名称（英文客户端）。
- 名称和你的游戏客户端一致（zh_MY：简体字＋台服用语）；台服繁体用 `--lang zh_TW`，国服用 `--lang zh_CN`。
- 为了不拖慢游戏：程序优先级调低，文字识别只用 1 个 CPU 核心、只在需要时运行。

## 功能
- **只为海克斯大乱斗服务**：进入其他模式（竞技场、召唤师峡谷等）会显示「暂停推荐」。所有胜率、装备清单、增幅池、
  加点/召唤师技能都来自海斗对局统计；**海斗英雄平衡调整**（造成/承受伤害、治疗、护盾、韧性、技能数值改动）
  会显示在「英雄玩法」里，并计入推荐：敌方造成伤害被削弱→威胁降低；你承受伤害增加→防御装更值；
  敌方治疗被加强→更需要重伤；承受伤害高的敌人更适合集火。
- **按分段推荐**：点摘要下方「胜率数据：全部分段 / 高分段」切换（会记住）；也可用 `--bracket high`。
- **网上胜率**（数据来源 ARAMKit，海斗专门统计，每期数千万场）：每局开始时读取你所用英雄的统计，并尽量贴合本局：
  - 装备：按你现在是第几件大件算；按你已选的增幅算（带某增幅时各装备的相对胜率）；
    按你已出的核心算（主流路线的下一件、三件核心后的常见后续）；
  - 增幅：按第几次选算；和你已选增幅的组合胜率；
  - 主流核心出装（显示在战术建议里）；台服中文的完整海斗增幅描述。
  评分 = 本局战况分析 + 网上胜率；增幅有胜率数据时以胜率为主。名称旁边标「胜率 xx%」。
  资料按版本缓存，每局只读一次你的英雄。连不上网站时自动只用本局分析。
- **只推荐本版本、海斗里真的有的东西**：
  - 装备 = 当前版本游戏数据里仍在海斗商店 **且** 海斗实际对局中能从商店买到的成品（排除增幅赠送、进化型、其他模式装备）；
  - 增幅 = 当前版本游戏数据里存在 **且** 海斗实际对局中出现过（已停用的不推荐，但屏幕上出现时仍能认出并打分）；
  - 胜率网站比游戏晚一个版本时会在界面注明；新版本刚加入的装备/增幅要等网站更新后才会被推荐。
- **英雄玩法**（开局 2 分半内自动展开，之后收起；点标题可手动切换）：
  - 加点顺序、召唤师技能：用网上实战数据，显示最多人用的，若另一种胜率明显更高也会列出；
  - 连招：170 个英雄的常用连招（附游戏里的技能名称）＋海斗玩法一句话；
  - 还没收录的新英雄（如洛克、尤娜拉、萨亨）会按技能描述自动推导连招，标注「仅供参考」。
- **战术建议**（依整体战局即时更新）：人数差（谁阵亡、几秒后复活）、双方装备/人头差、敌方打肥的核心、
  你的定位该怎么打、集火目标、阵容对位（开团 vs 消耗）、回复/控制/前排，以及双方增幅带来的打法变化。
  紧急情况（敌方多人阵亡、我方少人、你血量过低）会以橘色 ⚠ 显示在单行模式上。
- **装备推荐**（前 3 名，0-100 分 + 一句话理由 + 购买提示）：
  - **还没有二级鞋时单独推荐一双**（👟）：按网上这个英雄的鞋子胜率/购买率＋本局对面阵容（控制多→水星、物理多→钢盖…）；
  - **推荐平滑**：分数随时间渐变，排第一的装备只有在别的明显更好或你已经买了它时才换，不会一阵亡就乱跳；
  - 只推荐海斗里买得到的装备（排除竞技场、旧装备模式等其他模式的装备）；
  - 敌方越肥的人权重越高；按你当前实际的物理/魔法防御和生命算有效生命增幅；
  - 暴击/攻速已满会扣分；前期重核心、后期重针对；领先堆伤害、落后先保命；
  - 看所有人的装备和增幅：敌方重伤越多你的吸血越不值，队友已有重伤就不重复；
  - 不合你定位的装备不会只靠「克制」排上来；
  - 提示「可直接买 / 先买某零件 / 还差多少金」。
- **增幅**：
  - 只从海斗增幅池（170 个）里推荐；
  - **按 F8（或标题栏「识别三选一」）识别三选一**，打分并用 ★ 标出推荐；重骰后再按一次＝立即刷新。
    平时完全不识别、不占 CPU；识别到后只在三选一期间每 2 秒低频检查（发现重骰、记录选择），关掉就停。
    快捷键可用 `--hotkey F9` 等更换；
    **你在游戏里点选哪张卡会自动记录**（只在三选一画面出现时看鼠标点在哪，点「重骰」不会被当成选择），
    之后的出装/增幅推荐会考虑你已选的增幅；也可以在悬浮窗里点那张增幅卡片记下；
  - 部分海斗专属增幅没有公开描述，三选一时用屏幕上读到的描述来评分；
  - 识别不准时再按一次 F8 重新识别。

## 程序新版本（一键更新）
- 程序会检查这个仓库里的 `version.json`（启动后、以及不在对局时每 6 小时）。有新版本时标题栏显示金色「⇪ 新版 vX」，
  鼠标移上去看更新内容。
- **点一下就直接从 GitHub 更新**：只下载有变化的程序文件（`haidou_helper.py`、`lang_en.py`、`README.md`），
  每个都核对 SHA-256 校验码、检查语法，全部没问题才替换；旧文件留成 `.bak`。完成后标题栏显示「已更新 ✓」，**重新打开**即可。
- 只有你点了才会更新，不会自己下载。控制台模式输入「更新」回车。
- 更新出问题想还原：把 `.bak` 文件改回原名即可。

## 自建数据库（从游戏客户端收集）
- ⋯ →「自建数据库…」：预设**从游戏客户端收集**，不用密钥，客户端开着、不在游戏中就会在背景收集。
- 为什么不用 Riot 密钥：Riot 公开接口（match-v5）目前对海斗大乱斗的对局一律回 403，读不到；客户端自己的战绩接口读得到。
- 怎么收：先看你自己的最近 20 局，每局海斗读整局资料（10 人的英雄、装备、增幅、输赢）和时间线，
  再顺着同场玩家看他们的海斗对局往外扩。每次问客户端至少隔 1 秒、每轮最多 60 局，不拖累客户端。
- 资料存在 `%USERPROFILE%\.lol_haidou_helper\riotdb\`（matches.jsonl、timelines.jsonl），收集过程记在 collect.log。
- 某个英雄攒到 100 局以上后，推荐会加入这份数据：出这件 / 拿这个增幅时的胜率比这个英雄平均高多少（只看最近两个版本）。
- 仍可切换成「用 Riot 开发者密钥」（只有普通模式读得到，留作备用）。

## 实时胜率与关键时刻（2.1）

- **实时胜率**：战况条第一行「胜率 62% ↑5」（↑↓＝比 1 分钟前多 / 少几个百分点；低于 35% 变橘色），收起时也显示在第一行。
- 模型用你自建数据库收集的海斗对局**时间线**训练（Riot match-v5 timeline，每分钟双方的经济、人头、等级、拆塔）：
  P(我方赢) = σ( Σ β·x + Σ γ·x·u )，x = (已花经济差/1000, 人头差, 等级总和差, 拆塔差)，u = min(分钟, 30)/10
  （同样领先 3k，第 5 分钟和第 20 分钟意义不同）。岭回归（λ=1）、蓝红对调各一份所以没有截距；
  留 1/5 的对局检验，「第 8 分钟后准确率」显示在 ⋯ → 自建数据库。
- 需要 **150 局**时间线才会出现（从客户端收集时，每收一局就同时抓它的时间线）；之后每多 30 局自动重新训练。没有模型时不显示胜率。
- 对局中的经济用「装备总价」算（读不到别人的钱包），跟时间线的「总金钱 − 身上的钱」定义相同。
- **关键时刻**（赛后复盘）：每 10 秒记一次胜率，找出 2 分钟内**掉最多**（≥12 个百分点）和**涨最多**的一段，
  配上那段时间双方阵亡数，按规则判断原因：你第一个阵亡 → 站太前；开打时我方已少人 → 人数不利还接团；
  阵亡比对面多 2 个以上 → 团战换人吃亏；没人阵亡却掉 → 丢塔 / 兵线；否则经济被追上 → 对面装备成型。

## 4.1.2：每件装备都有搜索代号、自己选路线（物理 / 魔法 / 坦克…）

- **选路线**：出装页和增幅页上方都有路线按钮，**物理伤害 / 魔法伤害 / 坦克一定会列出来**（这个英雄平常不走的路线也能选），能走的话还有物理防御、魔法防御、减CD、治疗护盾。每个按钮是走这条路线的预估胜率，★ 最高。
  - （4.1.3 起）不再固定列出物理 / 魔法 / 坦克，只列这个英雄最常走的几条：按 ARAMKit 主流核心出装的选取率（没有就用自建库），占 8% 以上的、最多 4 条；鼠标移上去会写「x% 的人走这条」。例：金克丝只有物理；墨菲特有魔法 / 坦克 / 物防；赛特有物理 / 坦克。
  - 点一下就照你选的走：这条路线的装备 +2%，别的伤害类型的装备 −3%（保命 / 克制装本局需要时只扣 0.5%）；增幅同路线 +1%、相反伤害类型 −1%。再点一次或点 ✕ 回到自动。
  - 冷门路线（例：魔法金克丝）也会照实算胜率：用同一套公式（网上数据 + 契合度）估这条路线最好的两件，通常会比较低。

## 2.14：定路线

- **本局路线**：还没出大件时按英雄本身 + 已选增幅（转换属性的增幅也算）估一条「预定路线」（法术 / 物理输出 / 坦 / 辅助）；
  第一件大件做出来就锁定路线（之后按已出大件里最多的那条）。出装页第一行显示「本局路线：坦（由「班德尔笛子」定下）」。
- **同路线加分、换路线明显扣分**：例如贪啃奇第一件出了坦装，之后不会再推法术装；带生命的法强装这类两边都沾的算同路线。
  针对对面真正需要的保命 / 克制装只轻微扣分，并写明「偏离路线，但本局需要：…」；输出路线出纯坦装小幅扣分。
- **第一件不适合这个英雄**（例如坦克出了纯法强装）：按英雄本身的路线锁定并写明原因。
- **增幅跟着路线走**：锁定后，跟路线吻合的增幅加分，推向另一种伤害类型的增幅扣分。
- **按胜率定路线（2.14.1）**：还没出大件时，用自建数据库（加上网上主流出装，最多当 3000 局）算这个英雄走
  法术 / 物理输出 / 坦 各自的胜率，再按本局阵容（我方已有几个 AP、敌方 AP / 前排数）和已选增幅调整，选预估胜率最高的那条
  （样本 < 30 局或差不到 0.5 个百分点就按属性）。出装页显示例如「预定路线：法术（预估胜率 法术 51.9% · 物理输出 46.7%）」。
  路线模型存在 riotdb/pathmodel.json，对局多了 10% 会自动重练。
  验证（2317 局、交叉验证）：走模型推荐路线的胜率 49.2%，没走的 47.9%；模型认为差 3 个百分点以上却没走的只有 45.3%。

## 选英雄阶段推荐
进入海斗的选英雄画面时（客户端开着、助手开着就行），挂件会读取你的英雄、备选席和队友（本机客户端接口，只读），

```

海斗胜率项 = clamp(0.5 + 8 × (胜率 − 50%) × n/(n+5000), 0, 1)

阵容项     = 0.3 + 补上队伍缺的（前排 / 魔法伤害 / 开团 / 治疗保护）每项 +0.25，最高 1
```

## 敌方增幅预警

敌人拿到增幅时，战况条多一行（刚出现 30 秒内橙色，收起时也会显示）：

```
敌增幅  维迦「暴击治疗」→ 出重伤 +2
```

危险度 = 0.7 × 稀有度 + Σ 增幅关键词权重（保命 2、吸血/护盾/真伤/百分比 1.5…），只显示最危险的一个，增幅页列出全部。

如果游戏没提供敌方增幅，增幅页会提示。每局 7 分钟时会存一份游戏资料到 last_live.json（只在本机）。

## 已选增幅怎么影响出装

1. **出装方向**：每个已选增幅的属性（物攻、攻速、吸血…）以 0.2 的权重并入你的出装方向，契合度 F 跟着变。
2. **联动**：装备属性和某个增幅很像（余弦 > 0.5）→ 本局针对 +0.08。
3. **网上数据**：ARAMKit 有「带这个增幅时，出这件的胜率」就用（收缩 K=3000，样本 ≥300）。
4. **会改变出装的增幅**（按增幅编号判断，中英文客户端都适用）：

| 增幅 | 怎么变 |
|---|---|
| 拔剑吧（远程英雄） | 芮兰飓风箭、冲击火炮 −0.35；九头蛇 / 黑切 / 斯特拉克 / 死亡之舞 / 三相 / 星蚀等近战装 +0.12 |
| 灵活转换 | 物攻装当魔攻装看（1:1）；穿甲 −0.15、法穿 +0.08 |
| 转换恶作剧 | 魔攻装当物攻装看（×0.6）；法穿 −0.15、穿甲 +0.08 |
| 纯粹 - 法师 | 攻速装当技能急速装看；攻速 −0.25、命中效果 −0.15、急速 +0.06；鞋子改推爱欧尼亚 |
| 大绝电脑 | 急速只对大绝有效（已送 100）：急速装 −0.10 |
| 基本功夫 | 已送 70 急速：急速装 −0.06 |
| 溢流 / 因心成体 / 强化攻击 | 魔力装 +0.15 / +0.15 / +0.12 |
| 瞄准头部 | 暴击率 ≥40% 后暴击装 −0.15；无尽之刃 +0.10 |
| 毫发无伤 | 暴击装 +0.06（暴击率也是格挡率） |

   这些增幅让英雄平时的出装数据不适用，所以对应方向的装备（平时购买率 < 5%）不再被「几乎没人出」压分。

## 学最优解：怎么打出效果

推荐照样是最优解，旁边多教你「怎么用」：

- **三选一**：★ 那张下面一行绿字，例如「痛打一顿 怎么用：命中控制才触发：先控住再打」。
- **玩法页【怎么打出效果】**：你身上的主动装备按几号键、什么时候按（例如「按 2 中娅沙漏：残血或被集火时按」）；每个已选增幅怎么触发。
- **对局中提醒**：残血而且有中娅之类 → 战况条变成「残血 → 按 2 中娅沙漏」。
- **赛后「下局练习」**：只练一件事——带着中娅死了 ≥2 次就练按键；否则练你最主要增幅的触发方式。

增幅的触发方式按描述关键词判断（位移、控制、参与击杀、普攻、所选技能、大绝、残血、处决…）；按键是游戏默认装备键（1 2 3 5 6 7）。

## 向高手学

**向高手学**：每局结束，找出比你打得好的玩家（全场最强 + 和你同定位里最强，最多 2 个）。表现分 S 的单位是「每 10 分钟的人头」：

1. **功劳**：每次击杀算 1 分。单杀＝击杀者 1；有助攻＝击杀者 0.5，其余 0.5 由助攻者平分。
2. **净贡献** N = 功劳 − 死亡。一队 5 人的 N 加起来正好等于这队的人头差。
3. **扣掉团队效应**（赢的一方人人好看）：N′ = N − 0.8 × 队伍平均 N，只算你比队友多出来的（留 1/5 当自己那份）。
4. r = N′ ÷ 分钟 × 10；**信度修正** Z = n/(n+8)，n = 参与的击杀 + 死亡。
5. **结算数据**（对局结束后自动从客户端读，最多等 2 分钟）：输出、承伤（含减免）、给队友的治疗护盾、控制秒数各占全队几成，比平均多出多少（限制在 −20%～+30%），按 0.40 / 0.25 / 0.20 / 0.15 加权；全队治疗护盾不到输出 5% 的这项不算。加分 = 0.6 × 加权超出量 × 这队每 10 分钟的人头。坦克、辅助的价值靠这项算进来。
6. S = Z·r + 加分；比你高 1 以上才算「值得学」。
7. **跨局累积**：同一个英雄在你的对局里当过 2 次以上「值得学」，你玩它时玩法页会显示「高手出装」（最常出的核心装，单局的噪音靠多局抵消）。

- 出装顺序和时间、**强势期**（出了哪件之后 5 分钟内拿最多人头）、每 10 分钟死几次（和你比）、杀了你几次；
- 游戏不提供别人的增幅，所以高手经验只有出装和数据，没有增幅。

## 按你的习惯推荐（只存本机）
- 每局海斗结束时，程序在本机记下：英雄、出的成品装备、拿的增幅、三选一里出现过的增幅、输赢
  （`%USERPROFILE%\.lol_haidou_helper\habits.json`，最多 400 局，不上传）。打不到 5 分钟的局不记。
- 推荐时偏向你熟悉、而且你用了赢得多的装备 / 增幅：
  ```
  习惯加分 = 上限 × 熟悉度 × 战绩修正       （装备上限 0.10，增幅上限 0.15）
  熟悉度   = √(min(用的次数 / 这个英雄的局数, 60%) / 60%)          （增幅用「出现时选它的比例」）
  战绩修正 = 1 + clamp(5 × (你用它的胜率 − 你这个英雄的胜率) × n/(n+5), −0.5, +0.5)
  ```
  同一个英雄打满 2 局才开始加分；加分有上限，网上数据仍是主要依据。理由里会写「你常出（10 局里出了 7 局，赢 6 局）」。
- **自动读取你以前的对局**：启动时和每局结束后，从游戏客户端（本机接口，只读，不需要 API 密钥）读取你最近最多 200 局，
  把其中的海斗和普通大乱斗导入习惯记录（普通大乱斗只算装备）。客户端没开就跳过；⋯ →「我的习惯」→「从游戏客户端导入历史对局」可手动读取。
- 「玩法」页最上面显示你这个英雄的局数、胜率、常出装备。
- ⋯ →「我的习惯」可以关掉或清除记录。

## 数据来源
- **ARAMKit**（data.aramkit.com）：每个英雄的海斗出装 / 增幅 / 路线胜率（主要依据）。
- **arammayhem.com**（Data: arammayhem.com，CC BY 4.0）：国服海斗统计的增幅选取率、7 种语言的增幅名称
  （英文 / 简中 / 繁中客户端的卡名都认得）、编辑整理的「英雄 + 增幅」强力 / 陷阱组合。每天最多下载一次。
- **Riot Data Dragon / CommunityDragon**：当前版本的装备、英雄、技能、增幅资料。
- 其他网站（METAsrc、aramgg、Blitz、OP.GG 等）没有公开数据，或使用条款禁止程序抓取，所以没有接入。

## 推荐公式（2.0：用胜率说话）

每件装备、每个增幅显示两个数字，**单位都是胜率百分点**，而且分开写：

```
总分 = 网上数据 Δ*  +  本局调整
        （有误差范围）    （判断，不是数据）
```

**网上数据 Δ\*（ARAMKit 的汇总统计）**
1. 同条件比较，减少滚雪球偏差：装备看「这个英雄、第几件出它」的胜率 − 同一件所有装备的平均；增幅看「第几次选它」；
   带你已选的增幅时另外比一次（「带这个增幅时出这件」）；增幅和你已选增幅的组合也比一次。没有第几件的数据才用整局。
2. 经验贝叶斯收缩（同一张表一起看）：
   - 抽样方差 v = p(1−p)/n
   - τ² = Σ n·(Δ² − v) / Σ n（样本 ≥500 的选项、按样本加权；限制在 0.3%～5%）＝常见选项之间真正的差距
   - Δ* = Δ × τ²/(τ²+v)，误差方差 = τ²v/(τ²+v)（样本越少越往 0 拉，跟 Bühlmann 信度同一个思路）
3. 几个来源按精度加权平均；误差取最小的来源（来源彼此相关，不叠加），再加 0.5% 系统误差：±1.96·√(误差方差 + 0.5%²)。
4. 这个英雄几乎没人出的装备（没数据）：当作 −1%；没数据的增幅当作 0。
5. 已选增幅改变了出装（例如拔剑吧）、而这件平时很少人出：数据当 0，只看本局。

**本局调整（判断，单位同样是百分点）**
- 装备：6 × Σ 本局因素（对面回复强 → 重伤、前排厚、爆发高、控制多、增幅规则、你的习惯、自建数据库…；正面因素按契合度打折）
  + 2 × (契合度 − 0.6)，限制在 ±3%。
- 增幅：6 × Σ 本局因素 + 契合度项（有数据 ×1.5、没数据 ×4）+ 国服选取率（小幅），限制在 ±4%。

**要知道的限制**：汇总数据有选择偏差（赢的局钱多、能出到后期装），同条件比较只能减轻、不能消除；
样本几十万局时 ± 主要来自那 0.5% 的系统误差。总分在推荐之间随时间平滑（0.55 本次 + 0.45 上次），排第一的要被超过 0.5% 才换。

## 全屏玩怎么办
独占「全屏」下任何普通窗口都盖不到游戏上（能做到的只有注入游戏的外挂），截屏识别也会黑屏。
- 推荐：改成「无边框」，画面和全屏一样。
- 坚持全屏：双击 `start_web.bat`，窗口里会显示一个网址（如 http://192.168.1.5:8765），
  用同一 WiFi 的手机/平板或第二块屏幕打开，每 2 秒自动刷新。第一次运行 Windows 防火墙会询问，选「允许」。

## 说明
- 对局数据来自游戏官方的本地实时接口（127.0.0.1:2999，只读，Porofessor 等工具也用它）。
  不读内存、不注入、不替你操作。这个接口不提供增幅，所以三选一用本地截屏文字识别（离线，不上传）。
- 海斗三张地图（咆啸深渊、高辛渡口、屠戮大桥）都按海斗处理：同时看游戏模式名称和地图编号。
- 识别有问题时，在三选一画面按 F8，截图和识别文字会存到 `%USERPROFILE%\.lol_haidou_helper\debug\`。
- 其他参数：`--console` 文字模式，`--alpha 0.8` 透明度，`--scale 1.2` 字号，`--no-scan` 关闭屏幕识别，`--no-stats` 不用网上胜率，`--no-click` 不自动记录点选，`--auto-scan` 一直自动识别，`--hotkey F9` 换快捷键，
  `--web` 同时开网页查看，`--ui-lang en` 英文界面。
